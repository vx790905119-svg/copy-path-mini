复制路径 (Copy Path) 1.0.0

安装：双击 CopyPath-Setup-1.0.0.exe，按提示安装即可。
只为当前 Windows 用户安装，无需管理员权限，适用于 Windows 10 / Windows 11。

使用：右键文件、文件夹或文件夹空白处 → 复制路径 → Ctrl+V 粘贴。
复制得到的是完整路径文本，不加额外引号。此工具用于单个项目的路径复制。
Windows 11 若未直接显示，请打开右键菜单里的“显示更多选项”。

卸载：Windows 设置 → 应用 → 找到“复制路径 (Copy Path)” → 卸载。
也可以运行安装目录中的 Uninstall.exe。
如果安装前已有同名菜单，安装器会先备份，卸载时恢复。

特点：复制程序约 5.5 KB，用完即退出；无后台常驻、联网、广告、自动更新或额外安装依赖。
安装器只操作当前用户的两项右键菜单和卸载登记，不修改其他人的账户设置。
剪贴板被其他程序持续独占时，请稍后再点一次。

这是个人工具，尚未购买代码签名证书；Windows 或安全软件可能显示“未知发布者”。
不需要关闭系统安全防护。若系统阻止运行，请先向发送者核对文件来源。
