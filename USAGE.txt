English | 简体中文

ENGLISH

Install: double-click CopyPath-Setup-1.1.0.exe. Windows 10 / 11; no administrator rights required.
Setup follows your Windows display language: English or Simplified Chinese, with English as the fallback.
To override the setup language, use /LANG=en or /LANG=zh-CN.

Use: right-click a file, folder or folder background, choose Copy Path, then press Ctrl+V to paste.
On Windows 11, choose Show more options if the command is not visible.
Copies one full path as text, without extra quotation marks.

Uninstall: Windows Settings > Apps > Copy Path, or run Uninstall.exe in the installation folder.
Existing commands with the same name are backed up and restored when you uninstall.

The helper is about 5.5 KB and exits immediately after use. No background process, network access, ads or automatic updates.
If another application is holding the clipboard open, try again shortly.
This personal utility is unsigned. Keep Windows security protections enabled and verify the download source if it is blocked.

简体中文

安装：双击 CopyPath-Setup-1.1.0.exe。适用于 Windows 10 / 11，无需管理员权限。
安装界面按 Windows 显示语言自动选择英文或简体中文，其他语言回退到英文。
也可通过 /LANG=en 或 /LANG=zh-CN 指定安装语言。

使用：右键文件、文件夹或文件夹空白处 → 复制路径 → Ctrl+V 粘贴。
Windows 11 若未直接显示，请打开“显示更多选项”。每次复制一个完整路径，不加额外引号。

卸载：Windows 设置 → 应用 → 复制路径，或运行安装目录中的 Uninstall.exe。
安装前已有的同名菜单会自动备份，卸载时恢复。

核心程序约 5.5 KB，用完即退出；无后台常驻、联网、广告或自动更新。
剪贴板被其他程序持续独占时，请稍后再点一次。
此个人工具未做代码签名；请保留 Windows 安全防护，遇到拦截时先核对下载来源。
